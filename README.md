# VitalDB Hypothermia Secondary Analysis

Secondary analysis of VitalDB v1.0.0 (PhysioNet) testing whether cumulative
intraoperative hypothermic burden predicts blood loss, transfusion, and
downstream outcomes. 

## Reproducing this analysis

### 1. Get the data (not included in this repo)

This repo does **not** redistribute VitalDB's raw data, even though its
CC BY 4.0 license permits it — the canonical copy on PhysioNet is
authoritative and versioned, and re-hosting a copy here would just add
~25MB of clinical data to a code repo for no benefit.

Download VitalDB v1.0.0 from PhysioNet (DOI [10.13026/czw8-9p62](https://doi.org/10.13026/czw8-9p62))
and place it as a sibling directory of this repo, i.e.:

```
vitaldb/
  DATASET/              <- VitalDB files go here (clinical_data.csv, lab_data.csv, etc.)
  project/               <- this repo
```

Every script resolves `DATASET/` as `PROJECT_DIR.parent / "DATASET"` — if
you clone this repo somewhere else, `DATASET/` must sit one level above it
with that exact name.

### 2. Set up the environment

```
python -m venv .venv          # create as a sibling of this repo, matching DATASET/'s placement
.venv/Scripts/activate         # Windows; use .venv/bin/activate on Linux/Mac
pip install -r project/requirements.txt
```

`requirements.txt` is a full `pip freeze` (pinned exact versions, not just
top-level packages) — this is what the manuscript's numbers were actually
produced with. `vitaldb.load_case()` in `02_build_exposures.py` requires
live network access to `api.vitaldb.net`; everything else is local-only.

### 3. Run the pipeline

Scripts are numbered in dependency order and must be run in sequence —
each reads the previous step's output from `data/` (gitignored,
regenerated locally):

```
python scripts/01_extract_cohort.py          # candidate cohort, no network
python scripts/02_build_exposures.py         # streams BT/ART_MBP tracks, ~50 min for the full cohort
python scripts/02b_coverage_bias_check.py
python scripts/02c_aim4_cohort.py
python scripts/03_build_outcomes.py
python scripts/03b_extend_comparison_table.py
python scripts/04_analysis_primary.py
python scripts/04b_followups.py
python scripts/04c_v1_comparison.py
python scripts/04d_preop_hb_sensitivity.py
python scripts/05_analysis_secondary.py
python scripts/07_tables_figures.py
python scripts/08_select_references.py       # requires pubmed-Hypothermi-set.nbib, see note below
python scripts/09_generate_pdf.py            # -> VitalDB_Hypothermia_Manuscript.pdf
```

(There is no `06` — that slot was reserved for Aim 4, which is deferred;
see the protocol's §2/§3b for why.)

`02_build_exposures.py` is checkpointed and resumable (`data/checkpoint_completed_caseids.txt`)
— if it's interrupted by a network failure partway through, re-running it
picks up where it left off rather than restarting from case 1.

### 4. Outputs

- `data/` — intermediate parquet/CSV files, regenerated locally, gitignored.
- `outputs/tables/` — all numbered tables as CSVs, `manifest.csv` indexes
  them all with descriptions and existence checks.
- `outputs/figures/` — all figures as 600dpi PNGs.
- `RESULTS_PROVENANCE.md` — maps every number in the manuscript back to
  the exact script and git commit that produced it.

### Note on `08_select_references.py`

This parses a local PubMed search export (`pubmed-Hypothermi-set.nbib`,
not included in this repo) to select and rank the reference list. If
you don't have that file, skip this step — `references_formatted.md`
(committed) already has its output, and `09_generate_pdf.py` doesn't
depend on re-running it.

## Repository structure

```
project/
  data/                # gitignored, regenerated by running the pipeline
  scripts/              # numbered pipeline stages, see above
  outputs/
    tables/             # gitignored, regenerated
    figures/            # gitignored, regenerated
  VitalDB_Hypothermia_Manuscript_Proposal.md   # locked protocol, source of truth

  RESULTS_PROVENANCE.md                         # number -> script -> commit trail
  references_formatted.md                       # reference list (Annals of Surgery style)
  requirements.txt
```
